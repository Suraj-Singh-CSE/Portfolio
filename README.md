# Suraj Singh - Portfolio

A portfolio landing page built from Figma design, featuring a dark theme with purple accents.

## Design

Based on the Figma design with:
- **Colors**: Background `#282C33`, Primary `#C778DD`, Gray `#ABB2BF`
- **Font**: Fira Code (monospace)
- **Sections**: Hero, Quote, Projects, Skills, About, Contact, Footer

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Build for production

```bash
npm run build
```

Static files will be in the `dist` folder.
